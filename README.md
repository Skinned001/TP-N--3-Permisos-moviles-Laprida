# ReportesInstituto

Aplicación móvil de reportes de desperfectos del Instituto Politécnico Formosa.

## Requisitos

- Node.js LTS
- npm
- Expo Go o un emulador Android/iOS

## Instalar y ejecutar

```bash
npm install
npm start
```

Para iniciar directamente en una plataforma:

```bash
npm run android
npm run ios
npm run web
```

El proyecto usa Expo Router con las rutas en `src/app`.
